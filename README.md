# Warung Bang Kobra - POS & DQM Delivery System

Sistem Point of Sale (POS) dan Pengiriman Khusus DQM (Delivery & Takeaway) untuk **Warung Bang Kobra**.

## 🚀 Fitur Utama
- **Kasir & POS Realtime**: Antrean pesanan, status meja, kalkulasi diskon, pajak, dan cetak struk thermal.
- **DQM Delivery**: Pelacakan kurir armada, estimasi waktu, status pengantaran, dan integrasi WhatsApp.
- **Firebase Firestore Live**: Sinkronisasi data realtime multi-device (pesanan, produk, kurir, kasir).
- **Manajemen Menu & Stok**: Pembaruan harga, foto menu, dan riwayat penyesuaian stok.
- **PWA & Offline Ready**: Desain responsif bergaya aplikasi mobile Android dan desktop.
- **Ready for Vercel**: Dilengkapi konfigurasi SPA routing `vercel.json`.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Database & Auth**: Google Firebase / Cloud Firestore
- **Deployment**: Vercel

## 📦 Menjalankan Secara Lokal
```bash
npm install
npm run dev
```

Build untuk produksi:
```bash
npm run build
```
